1. Open the file and enable the sidebar

  1. Open weltall-rigged.blend in Blender 5.0.
  2. Open the Scripting workspace. In the Text Editor's text dropdown, select RIG CONTROLS - Run Script.
  3. Hover over the Text Editor and press Alt+P, or click Run Script ▶.
  4. Return to Layout, select the rig, and enter Pose Mode.
  5. Press N in the 3D viewport and open the Weltall Rig tab.

Run the script once each time you reopen Blender. It registers the sidebar and dynamic keying sets; no add-on or automatic execution is required. Bone Properties custom properties remain available without it. The blend also contains this information in WELTALL ANIMATION GUIDE.

Frame 1 is the original neutral model. The Reference animations NLA track plays the unique source actions back-to-back from frame 31 at 30 fps. The Action Editor also lists them individually. Textures are packed into the blend and use nearest sampling.

2. Pose with FK, IK, and body controls

Blue controls are left, red are right, and gold are central. Select controls in Pose Mode. Use G for an editable translation and R for an editable rotation. Scale and inappropriate transform channels are locked. The original rigid parts retain fixed limb lengths.

ControlUse
CTRL-rootPlace and turn the entire character.
CTRL-bodyShift whole-body weight. Root/world IK goals can stay planted.
CTRL-pelvisMove the legs and skirt independently of the upper torso.
CTRL-chest_poseTurn shoulders, torso shell, head, and wings together.
FK limb ringsRotate individual upper arms, forearms, thighs, shins, wrists, and ankles.
Wrist/foot boxesMove/rotate an IK goal and set its ik_blend.
Elbow/knee diamondsMove a pole to choose limb bend direction.
Foot/toe, armor, skirt, wing controlsPose separate rigid details. Foot/toe controls follow the evaluated ankle.

The legacy CTRL-hips is the torso base; it does not carry the leg sockets. Legacy CTRL-chest is the shoulder girdle. Their original names and source curves are preserved; the sidebar labels their actual roles.

Use IK

  1. Work on a copied reference action or a new action; mute competing reference playback when posing a new action.
  2. Place the wrist/foot IK target and its elbow/knee pole.
  3. On that wrist/foot, move FK / IK from 0 toward 1.
  4. Key the active limb channels using the sidebar's Key button or a Weltall keying set.

Zero is FK; one is IK; intermediate values blend smoothly. Reference actions begin entirely in FK and do not animate IK targets, poles, or blends. There is no automatic matching or snap button: the IK pose is the pose you set. Avoid sweeping a pole through a fully straight limb; beyond full reach the chain clamps instead of stretching.

Each wrist has Hand: 0 open, 1 closed, 2 both, 3 hidden. Rest/reset is 2, preserving the original extracted visibility. Key the hand state to animate a swap.

3. Use foot and hand contacts

Contact controls start at zero and operate through that limb's IK blend. Use local axes. Forward is negative Y.

Full names use CTRL- and .L/.R, for example CTRL-heel_contact.L. Native foot/toe FK controls remain available for individual pieces. Head, knee/thigh armor, and skirt also retain their permitted sliding channels for clearance.

4. Choose what a control follows

ControlSpacesDefault
Wrist/foot IK targetsRoot / Body / WorldRoot
Elbow/knee polesRoot / Body / GoalRoot
Head orientationTorso / Root / WorldTorso

Root carries a control with character placement; Body carries it with the body; World keeps it fixed when root/body move. Goal makes a pole travel with its IK target. Head position always follows the torso; only its orientation changes space.

Use Change Follow (Keep Pose) in the sidebar. It compensates the control so the current evaluated pose stays in place. It keys the previous pose/space one frame earlier and the compensated pose/new space now, with stepped follow keys. This also works in NLA Tweak Mode.

A follow button writes animation keys even with Auto Key off. Use it on your working action. Editing the raw follow property does not compensate the pose. Follow changes are separate from the FK/IK blend.

5. Edit a reference action without losing it

  1. In the NLA Editor, select the source strip. Duplicate it with Shift+D and move the copy onto a separate working track.
  2. Make the copied strip's action single-user with Edit → Make Single User (U), then rename it.
  3. Select the copied strip and press Tab in the NLA Editor to enter Tweak Mode. Edit its action in the Action Editor.
  4. Press Tab in the NLA Editor to leave Tweak Mode. Keep the original Reference animations track intact and mute competing tracks as needed.

For fresh animation, mute Reference animations and create a new Action in the Action Editor. Name it and enable its shield/Fake User if it has no NLA strip.

Select, key, and use pose tools

Use the sidebar Select buttons or the six saved selection sets in Armature Data Properties: Whole Body, Body, Arm L/R, and Leg L/R. Seven dynamic keying sets add Selected. The sidebar Key buttons and keying sets include active FK channels at blend 0, active IK at blend 1, both between them, and relevant hand/blend/follow properties. Selecting only a detail control keys only that control.

Blender's Copy Pose, Paste Pose, Paste Flipped Pose, and X-axis mirroring work with the controls. Breakdown, Push/Relax, and Blend to Neighbor need surrounding keys on the working action. Keep source controls in quaternion rotation mode; converting them changes interpolation. Added contact and offset controls use Euler rotation.

Key channels an action should own. Import resets animation-controlled channels to recorded neutral values between independent actions, preventing a saved pose in one clip from contaminating another. Unkeyed manual offsets remain shared across actions until keyed.

6. Reset and explore the demonstrations

The Asset Browser's Current File library contains five partial neutral poses: Body, Arm L, Arm R, Leg L, and Leg R. Select the controls to affect, then apply or blend the asset. Apply Pose Flipped uses corresponding .L/.R names. Body Neutral preserves global root placement. Create your own partial pose assets with Pose → Pose Library → Create Pose Asset.

Alt+G and Alt+R clear editable translation and rotation. Backspace over a custom property restores its default. Clear Transforms alone does not reset hand, blend, or follow properties.

Switch actions cleanly

  1. Leave NLA Tweak Mode and turn Auto Key off.
  2. Mute Reference animations and clear the active Action with its X in the Action Editor.
  3. In Pose Mode, select Whole Body and fully apply all five Current File neutral assets.
  4. Select CTRL-root and press Alt+G, then Alt+R.
  5. Choose the next demo/action. To return to references, leave the Action empty, unmute Reference animations, and scrub to the desired frame.

Seven separate 61-frame DEMO/ actions demonstrate Walk contacts, Weight transfer, Crouch, Landing, Punch, Bracing, and Follow and blend. They are editable contact studies, not original game motion. The 91 reference actions remain separate.

7. Reshape the model

Return to frame 1 and reset to neutral before mesh editing. Select an original mesh object and edit its vertices or UVs in Edit Mode. Coincident triangle vertices are joined for editing while preserving UV corners and authored normals. Materials keep the original packed pixel textures.

Keep original object names, parenting, origins, transforms, and material assignments. Do not join separate original objects, apply the rig's constraints, or rename native joints. Save a separate edited blend so the generated original remains available.

8. Bake edits into the local model package

Keep the build's original/weltall folder. From the extracted release directory, run:

.\weltall-rig.cmd import "D:\Weltall\weltall-edited.blend" --blender "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe" --original "D:\Weltall\original\weltall" --out "D:\Weltall-edited"

Choose a new output folder. Source users can replace .\weltall-rig.cmd with node cli.mjs. Import bakes the evaluated rig, including IK/contact motion and hand visibility, onto the original 51-joint hierarchy. Authoring controls and neutral pose assets are omitted from animation output.

The output is an edited local GLB/model package. This tool does not insert models into the game, patch a disc, or write the original game BIN format.

9. Know the source coverage

The audited original Weltall library contains 91 unique actions with 120 scene/battle source aliases. The blend's SOURCE ANIMATION COVERAGE text and rig-report.json record the aliases and timeline. Weltall-2, Xenogears, and Id are outside this release.

  • Scene08 motion is mapped onto the canonical battle skeleton using the audited source mapping.
  • Scene01_21 remains PARTIAL: source keyframe 44 is absent.
  • Battle animation uses a fixed neutral capture context. Cameras, sound, particles, and context-dependent battle effects are not part of this model animation.

The original mesh, hierarchy, and textures remain the basis of the export; the rig does not recreate missing source motion.
